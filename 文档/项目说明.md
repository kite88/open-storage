# 项目说明

这个仓库用的是 **熊猫存储工具**（Panda Storage Tool），把 GitHub 仓库当网盘用。

## 目录约定

| 目录 | 放什么 |
| --- | --- |
| `文档/` | 需求、会议纪要、对外说明这类文本材料 |
| `照片/` | 素材图与截图，程序会给缩略图预览 |
| `设计稿/` | 界面稿与配色文件 |

## 使用约定

1. 上传前先在自己的分支上确认目录，避免同级同名文件被自动重命名。
2. 图片请控制在 5 MB 以内，方便网页端直接预览。
3. 需要给外部引用的文件，复制外链时优先用 jsDelivr，国内访问更稳。
4. 空目录靠 `.gitkeep` 占位，不要在网页端把它删掉。

## 备注

仓库里的所有文件都只做演示用，可以随时清空。
