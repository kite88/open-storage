## 一、本次要解决的问题

文件散落在聊天记录、邮件附件和个人网盘里，找一份半年前的稿子要翻三个地方。
结论：先用一个公开的 GitHub 仓库把「能外链、能版本回溯」这件事跑通，再考虑换更正式的方案。

## 二、结论

1. 仓库按用途分目录：文档 / 照片 / 设计稿，一级目录不再加层级。
2. 上传工具要求：支持拖拽、支持整个文件夹递归上传、能直接拿到 raw 与 jsDelivr 外链。
3. 删除必须二次确认，重名默认自动重命名，避免覆盖别人刚传的稿子。
4. 传输记录要能看清「谁、什么时候、传了什么、成没成」，失败的要写清原因。
